# IGMO 점수 규칙

> 점수 계산의 권위는 백엔드에 있다. 프론트엔드는 서버가 보낸 점수와 점수 상세를 표시하며 점수를 임의로 재계산하지 않는다.

## 1. 낚시 점수

다른 플레이어가 내가 제출한 추측 프롬프트에 투표하면 득표 수만큼 점수를 얻는다.

```text
낚시 점수 = 내 추측 프롬프트의 득표 수 × 1점
```

예시:

```text
A의 추측 프롬프트에 3명이 투표
→ A는 3점 획득
```

## 2. 완벽 정답 점수

원본 프롬프트와 공백 제거 후 완전히 일치하는 추측을 제출하면 3점을 얻는다.

```text
완벽 정답 점수 = 3점
```

- 일반 정답 점수 2점은 중복 지급하지 않는다.
- 완벽 정답 후 제출한 가짜 프롬프트에는 낚시 점수가 적용될 수 있다.

## 3. 일반 정답 점수

원본 프롬프트에 투표한 일반 플레이어는 1명당 2점을 얻는다.

```text
일반 정답 점수 = 원본 프롬프트에 투표한 경우 2점
```

## 4. 출제자 점수

출제자는 원본 프롬프트가 일부 플레이어에게만 선택되었을 때 점수를 얻는다.

다음 값을 사용한다.

```text
Q = 원본 프롬프트에 투표한 일반 플레이어 수
P = 완벽 정답자 수
E = 출제자를 제외한 전체 플레이어 수
```

```text
Q = 0       → 출제자 0점
Q + P = E   → 출제자 0점
그 외       → Q × 2점
```

완벽 정답자는 투표하지 않지만, 모두가 정답을 맞혔는지 판단할 때는 정답자로 포함한다.

## 5. 라운드 점수와 누적 점수

- 라운드 점수는 해당 라운드에서 발생한 점수의 합계다.
- 누적 점수는 라운드 점수를 게임 전체에 누적한 값이다.
- 프론트는 서버가 보낸 `roundScore`, `totalScore`, `scoreDetails`를 표시한다.
- 프론트가 투표 목록을 보고 점수를 다시 계산하지 않는다.

점수 상세 사유는 다음을 사용한다.

- `PERFECT_GUESS`: 완벽 정답
- `CORRECT_ANSWER`: 원본 프롬프트 정답 투표
- `FOOLED_PLAYER`: 내 추측 프롬프트에 투표
- `QUESTIONER`: 출제자 점수

## 6. 최종 순위

- 최종 순위는 누적 점수 기준이다.
- 같은 점수는 같은 순위다.
- 다음 순위는 건너뛴다.

예시:

```text
철수 20점 → 1위
영희 20점 → 1위
민수 15점 → 3위
```
