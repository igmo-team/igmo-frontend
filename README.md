## 서비스 소개
AI가 생성한 이미지를 보고 원본 프롬프트를 추측하는 실시간 파티게임입니다.

플레이어들은 매 라운드 공개되는 이미지를 보고 각자의 추측을 제출합니다. 이후 모든 플레이어가 제출된 후보에 투표하고, 투표 결과에 따라 점수를 획득합니다. 라운드가 종료된 뒤 최종 점수를 기준으로 순위가 결정됩니다.

## 주요 기능

### AI 이미지 생성

매 라운드 AI가 생성한 이미지를 확인하고, 이미지의 원본 프롬프트를 추측할 수 있습니다.

## 게임 진행 방식

1. 라운드마다 AI가 생성한 이미지가 공개됩니다.
2. 플레이어들은 이미지의 원본 프롬프트를 추측해 제출합니다.
3. 제출된 추측 후보들이 플레이어들에게 공개됩니다.
4. 플레이어들은 후보 중 하나에 투표합니다.
5. 투표 결과에 따라 점수가 계산됩니다.
6. 모든 라운드가 끝나면 최종 점수에 따라 순위가 결정됩니다.

- AI 이미지와 창의적인 프롬프트를 활용한 게임을 즐기고 싶을 때
