# AGENTS.md

## Review guidelines

- For pull request reviews, write comments in Korean.
- Do not limit reviews to only critical or major issues; include actionable non-blocking issues when they affect correctness, maintainability, readability, testability, or user experience.
- If no blocking issue is found, still provide concise Korean feedback for any specific actionable non-blocking risks or explicitly state in Korean that no actionable issue was found.
- Avoid comments about formatting, import order, or unused imports unless they cause a real bug.
- For detailed review guidance, use `.github/codex/code_review.md`.
